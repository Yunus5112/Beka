# Beka Solutions - Boston Consulting Hub

Modern, professional website for Beka Solutions Boston Consulting Hub built with React, TypeScript, and Tailwind CSS.

## 🚀 Features

- **Modern Design**: Clean, professional interface with responsive design
- **Multi-language Support**: Turkish and English content
- **Service Management**: Dedicated pages for all business services
- **Appointment Booking**: Calendar-based appointment scheduling system
- **Payment Integration**: Ready for Stripe and PayPal integration
- **Contact Forms**: Professional contact and inquiry forms
- **SEO Optimized**: Semantic HTML structure and meta tags

## 🏢 Services

1. **Finansal Danışmanlık** (Financial Consulting)
   - SBA Loans
   - Grants-Hibeler

2. **Muhasebe Servisi** (Accounting Services) 
   - Personal Tax Return
   - Business Tax Return

3. **Noterlik ve Tercümanlık** (Notary & Translation)
   - Noterlik işlemleri
   - Tercüme işlemleri

4. **Sigorta Hizmetleri** (Insurance Services)
   - Şirket Kurulumu
   - Worker Comps & Business Insurance

## 🛠️ Tech Stack

- **Frontend**: React 19 with TypeScript
- **Styling**: Tailwind CSS 4
- **Routing**: React Router DOM
- **Icons**: Lucide React
- **Date Picker**: React DatePicker
- **Build Tool**: Vite
- **Package Manager**: NPM

## 📦 Installation

1. Clone the repository:
```bash
git clone <repository-url>
cd Beka
```

2. Install dependencies:
```bash
npm install
```

3. Start the development server:
```bash
npm run dev
```

4. Build for production:
```bash
npm run build
```
